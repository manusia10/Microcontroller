# Microcontroller STM32 Course

Repository นี้เป็นชุดโปรเจกต์สำหรับเรียนวิชา Microcontroller / STM32 โดยใช้ภาษา C และ STM32 HAL Library เพื่อฝึกการใช้งานอุปกรณ์ตัวประกัน (MCU) อย่างเป็นระบบ ตั้งแต่พื้นฐานการควบคุม GPIO ไปจนถึงการประยุกต์ใช้งานเชิงระบบ เช่น ตัวจับเวลา การตัดต่อ Interrupt การอ่าน ADC และการแสดงผลบน LCD

## วัตถุประสงค์ของรายวิชา

- เข้าใจหลักการทำงานของไมโครคอนโทรลเลอร์ STM32
- เรียนรู้การเขียนโปรแกรมควบคุม Hardware ผ่าน HAL Library
- ฝึกการใช้งาน GPIO, Timer, Interrupt, ADC และการสื่อสารแบบต่าง ๆ
- พัฒนาโปรแกรมแบบฝึกหัดจากง่ายไปยาก พร้อมเชื่อมต่อกับอุปกรณ์ภายนอก

## ขั้นตอนการเตรียมเครื่อง

### 1. เตรียมอุปกรณ์ที่จำเป็น

- บอร์ด STM32 ที่ใช้งาน เช่น STM32 Nucleo, Discovery หรือบอร์ดที่สอดคล้องกับขาใช้งาน
- USB cable สำหรับเชื่อมต่อบอร์ดกับคอมพิวเตอร์
- ST-Link / Programmer หรือ USB ST-LINK ที่ติดมากับบอร์ด
- จอแสดงผล LCD (ถ้ามีในแล็ป)
- สาย jumper และอุปกรณ์อินพุต/เอาต์พุต เช่น LED, Button, 7-segment
- ไฟล์และ library ของ STM32 HAL / STM32CubeIDE

### 2. ติดตั้งซอฟต์แวร์ที่จำเป็น

1. ติดตั้ง STM32CubeIDE
   - ดาวน์โหลดจากเว็บไซต์ทางการของ STMicroelectronics
   - เลือกเวอร์ชันที่เข้ากันกับระบบปฏิบัติการของเครื่อง
2. ติดตั้ง ST-Link driver
   - หากเครื่องไม่สามารถ detect บอร์ด STM32 ได้ ให้ติดตั้ง Driver ให้เรียบร้อย
3. ติดตั้งโปรแกรมสำหรับบอร์ด STM32 เช่น STM32CubeProgrammer (ถ้าจำเป็น)
4. ตรวจสอบว่าเครื่องคอมพิวเตอร์สามารถเข้าถึงบอร์ดผ่าน USB ได้

### 3. ตั้งค่าบอร์ดและ Project

1. เปิด STM32CubeIDE
2. สร้าง Project ใหม่
3. เลือก MCU รุ่นที่ใช้
4. ตั้งค่าพอร์ต I/O ที่ต้องการใช้งาน เช่น GPIO, USART, ADC, TIM
5. Generate Code จาก CubeMX
6. ตรวจสอบไฟล์หลัก `main.c` และแก้ไขโค้ดตามแล็ป
7. Build โปรเจกต์ (Compile)
8. Flash ไปยังบอร์ด STM32

### 4. ขั้นตอนการอัปโหลดโค้ด

1. เชื่อมต่อบอร์ด STM32 เข้ากับคอมพิวเตอร์ผ่าน USB
2. ตรวจสอบว่ามีไฟติดและบอร์ดถูก detect แล้ว
3. เลือก Target Device ใน STM32CubeIDE
4. กด Run / Debug เพื่อ Build และ Upload
5. หากโปรแกรมทำงานผิดพลาด ให้ตรวจสอบ:
   - พอร์ต USB
   - Driver ST-Link
   - สายต่อ GPIO
   - Clock และ Pin Configuration

### 5. ข้อแนะนำก่อนเริ่มทำแล็ป

- อ่านคำอธิบายแล็ปให้ละเอียด
- วางแผนการต่อวงจรก่อนเริ่มทำงาน
- ควรใช้โค้ดแบบ modular และคอมเมนต์ให้ชัดเจน
- ทดสอบทีละส่วน เช่น LED ก่อน, Button ต่อ, LCD ต่อ แล้วจึงรวมโค้ดเข้าด้วยกัน
- จดบันทึกผลการทดลองและข้อผิดพลาดที่พบ

## การทำแล็ปแต่ละแล็ป

### MCU_Lab_01: เบื้องต้นกับ GPIO และการควบคุม LED

#### Lab1_3_LED
- ศึกษาการควบคุม LED ด้วย GPIO
- เรียนรู้การสั่ง ON/OFF แบบง่าย
- ฝึกการทำงานพื้นฐานของพอร์ต I/O

#### Lab1_4_SOS
- สร้างรูปแบบการกระพริบ LED แบบ Morse code SOS
- ฝึกการใช้ delay และการเขียนลูปการทำงานแบบต่อเนื่อง

### MCU_Lab_02: HAL Programming และ Interrupt

#### Lab2_1_HALpolling
- เรียนรู้แนวคิดการใช้งาน HAL แบบ Polling
- ให้ความสนใจว่าพอร์ต I/O ทำงานอย่างไรเมื่อโปรแกรมตรวจสอบสถานะแบบวนซ้ำ

#### Lab2_2_HAL_interrupt
- ศึกษาการใช้งาน Interrupt สำหรับการตอบสนองต่อเหตุการณ์
- ปรับปรุงประสิทธิภาพการทำงานของระบบ

#### Lab2_3_LED Blinking
- เขียนโปรแกรมให้ LED กระพริบแบบคงที่
- ฝึกเรื่อง Timer / Delay และการรองรับการทำงานอัตโนมัติ

#### Lab2_4_LED Blinking_timer+interrup
- รวมการใช้งาน Timer กับ Interrupt
- นำเสนอแนวทางการสร้างระบบที่ทำงานแบบอัตโนมัติและตอบสนองต่อเหตุการณ์ทันที

### MCU_Lab_03: Digital Input, Delay, Seven-Segment และการควบคุมหลาย output

#### Lab3_1_LED Blinking_Blocking
- เรียนรู้การใช้ delay แบบ blocking
- เห็นถึงข้อจำกัดของการทำงานแบบหยุดพัก (blocking delay)

#### Lab3_1_LED Blinking_non-block
- สร้างระบบ LED กระพริบแบบ non-blocking
- ปรับปรุงให้โปรแกรมสามารถทำงานได้หลายอย่างพร้อมกัน

#### Lab3_2_LED Blinking_Button
- ใช้ปุ่ม (button) เป็นอินพุตเพื่อสั่ง LED
- เรียนรู้การอ่านสัญญาณจากปุ่มและประเมินการกดแบบเบื้องต้น

#### Lab3_3_Segment
- เรียนรู้การควบคุม 7-segment display
- เอาต์พุตแบบตัวเลขบนอุปกรณ์แสดงผลดิจิทัล

#### Lab3_4_LED 7-segment
- รวมการควบคุม LED และ 7-segment display
- เรียนรู้การควบคุมหลาย output พร้อมกัน

#### Lab3_5_LED 7-segment_button
- เชื่อมปุ่มกับ 7-segment display
- สร้างระบบอินพุต-เอาต์พุตเชิงปฏิสัมพันธ์

### MCU_Lab_04: LCD แสดงผลและการทำงานแบบ Interactive

#### Lab4_1_Hello World LCD
- สร้างข้อความขึ้นบน LCD
- ศึกษาเรื่องการส่งข้อมูลไปยัง LCD แบบพื้นฐาน

#### Lab4_2_back light LCD
- ใช้งาน backlight ของ LCD
- ทำให้หน้าจอสว่างและอ่านข้อความง่ายขึ้น

#### Lab4_3_LCD Button
- ใช้ปุ่มควบคุมการแสดงผลบน LCD
- ฝึกการประมวลผลอินพุตและแสดงข้อความตามสถานะ

#### Lab4_4_LCD Member list
- แสดงรายชื่อสมาชิกหรือข้อมูลแบบ list บน LCD
- พัฒนาทักษะการจัดรูปแบบข้อความและการใช้งานแสดงผลแบบหลากหลาย

### MCU_Lab_05: ADC, Sensor และการสื่อสารกับคอมพิวเตอร์

#### Lab5_1_ADC
- เรียนรู้การใช้งาน ADC ของ STM32
- อ่านค่า analog จาก sensor หรือปุ่มปรับค่า

#### Lab5_2_ADC LCD
- นำค่า ADC มาแสดงบน LCD
- ฝึกการแปลงข้อมูลแบบ analog เป็นข้อมูลที่ใช้งานได้บนจอแสดงผล

#### Lab5_3_USB-to-UART
- เรียนรู้การสื่อสารข้อมูลระหว่างบอร์ด STM32 กับคอมพิวเตอร์ผ่าน USB/UART
- ฝึกการส่งข้อมูลเช่นค่าตัวแปรหรือข้อความไปยัง Serial Monitor

## เทคนิคและมาตรฐานการเขียนโค้ด

- ตั้งชื่อ Pin ให้เหมาะสมและชัดเจน
- ใช้โค้ดตัดออกเป็นฟังก์ชันที่ทำหน้าที่ชัดเจน
- ส่งความเห็นและคอมเมนต์ในโค้ดเพื่ออธิบายจุดประสงค์
- ตรวจสอบค่า clock, baudrate และ pin mapping ก่อน flash
- แยกส่วนการตั้งค่าและส่วนความลอจิกของโปรแกรมให้ชัดเจน

## ปัญหาที่พบบ่อย

- ไม่ detect บอร์ด STM32 ใน STM32CubeIDE
  - ตรวจสอบ USB cable
  - ตรวจสอบ ST-Link driver
  - ทดสอบพอร์ต USB เครื่องใหม่
- LED ไม่ติด
  - ตรวจสอบ pin mapping
  - ตรวจสอบความสัมพันธ์ระหว่าง Port และ Pin
  - ตรวจสอบความผิดพลาดในการตั้งค่า GPIO mode
- LCD ไม่แสดงผล
  - ตรวจสอบการต่อสาย VSS, VDD, VO, RS, RW, E
  - ตรวจสอบแรงดันและ backlight
- ADC อ่านค่าไม่ถูกต้อง
  - ตรวจสอบ source input
  - ตรวจสอบ ADC configuration และ reference voltage
